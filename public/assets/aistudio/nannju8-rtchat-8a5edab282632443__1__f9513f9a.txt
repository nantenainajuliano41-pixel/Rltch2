# 💬 Discussions de groupe en temps réel

Application de messagerie de groupe : **React + Vite + Tailwind CSS** côté frontend (hébergé sur **Netlify**), **Supabase** pour tout le backend (Auth, PostgreSQL + RLS, Realtime). Aucun serveur personnalisé.

Seuls les utilisateurs inscrits et connectés peuvent voir les groupes et les messages. Un visiteur non connecté ne voit que l'écran de connexion / inscription, et la base de données refuse de toute façon tout accès au rôle `anon` (Row Level Security).

## 1. Configurer Supabase

1. Créez un compte sur <https://supabase.com> puis cliquez sur **New project** (choisissez un nom, un mot de passe de base de données et une région proche de vos utilisateurs). Attendez la fin de l'initialisation.
2. **Lancer le SQL** : menu de gauche **SQL Editor** → **New query** → copiez-collez tout le contenu de `supabase/schema.sql` → **Run**. Vous devez voir « Success. No rows returned ».
   Le script crée les tables, le trigger de création de profil, les politiques RLS, active le Realtime et crée le groupe « Général ». Il peut être relancé sans danger.
3. **Récupérer les clés** : **Project Settings** (engrenage) → **API** (ou **API Keys**) :
   - **Project URL** → valeur de `VITE_SUPABASE_URL`
   - clé **anon / public** → valeur de `VITE_SUPABASE_ANON_KEY`

   ⚠️ N'utilisez **jamais** la clé `service_role` dans le frontend.
4. **Confirmation par email** : **Authentication** → **Sign In / Providers** (ou **Providers → Email**) → option **Confirm email** :
   - **Désactivée** : l'utilisateur est connecté immédiatement après l'inscription (pratique pour les tests).
   - **Activée** : l'utilisateur reçoit un email et doit cliquer sur le lien avant de se connecter. L'application affiche alors « Vérifiez vos emails ».
5. **URL du site** (important si la confirmation par email est activée) : **Authentication** → **URL Configuration** → renseignez **Site URL** avec l'adresse Netlify (ex. `https://mon-chat.netlify.app`) une fois le site déployé. Pour les tests locaux, ajoutez `http://localhost:5173` dans **Redirect URLs**.
6. Vérification Realtime : **Database** → **Publications** → `supabase_realtime` doit contenir les tables `messages` et `groups`.

## 2. Tester en local

```bash
npm install
cp .env.example .env      # puis éditez .env avec vos deux valeurs
npm run dev
```

Ouvrez <http://localhost:5173>. Pour tester le temps réel : ouvrez deux navigateurs (ou une fenêtre de navigation privée), créez deux comptes différents, puis écrivez dans « Général ».

Build de production : `npm run build` (le résultat est dans `dist/`), aperçu : `npm run preview`.

## 3. GitHub puis Netlify

### Déployer sur Netlify

1. Sur <https://app.netlify.com> : **Add new site** → **Import an existing project** → **GitHub** → choisissez votre dépôt.
2. Les réglages de build sont lus depuis `netlify.toml` (commande `npm run build`, dossier `dist`).
3. Avant de déployer, ouvrez **Site configuration → Environment variables** (ou **Add environment variables** sur l'écran de création) et ajoutez :
   - `VITE_SUPABASE_URL` = l'URL de votre projet Supabase
   - `VITE_SUPABASE_ANON_KEY` = la clé anon
4. Cliquez sur **Deploy**. Si vous ajoutez les variables après coup, relancez un déploiement (**Deploys → Trigger deploy → Clear cache and deploy site**), car Vite les intègre au moment du build.
5. Copiez l'URL Netlify obtenue dans Supabase → **Authentication → URL Configuration → Site URL** (étape 1.5).

## Sécurité — résumé

- RLS activé (et forcé) sur `profiles`, `groups`, `messages`. Aucun privilège pour `anon` sur les tables.
- Lecture réservée au rôle `authenticated` ; insertion de groupe seulement si `auth.uid() = created_by` ; insertion de message seulement si `auth.uid() = user_id` (pas d'usurpation) ; suppression de message seulement si `auth.uid() = user_id`.
- Les messages sont affichés comme du texte par React (aucun `dangerouslySetInnerHTML`).
- Seules l'URL du projet et la clé `anon` sont présentes dans le frontend.
- La fonction `is_username_available` (appelable sans connexion) ne renvoie qu'un booléen pour signaler un pseudo déjà pris pendant l'inscription. Pour la supprimer : `drop function public.is_username_available(text);` — l'inscription continuera de fonctionner, l'unicité restant garantie par la base.

## Notes techniques sur le temps réel

- Les `INSERT` sont filtrés côté serveur par groupe (`group_id=eq.<id>`).
- Les `DELETE` ne peuvent pas être filtrés par colonne dans Supabase Realtime (seule la clé primaire est transmise) : l'application retire donc simplement l'`id` reçu s'il est affiché.
- Les doublons sont évités par l'`id` du message (l'expéditeur voit son message immédiatement, l'évènement temps réel est ignoré).
- Chaque canal est supprimé (`removeChannel`) au changement de groupe, à la déconnexion et à la fermeture de la page. À la (re)connexion du canal, l'historique est rechargé pour rattraper les messages manqués.

import { useCallback, useEffect, useState } from "react";
import { AuthProvider, useAuth } from "./context/AuthContext";
import { isSupabaseConfigured } from "./lib/supabase";
import { useGroups } from "./hooks/useGroups";
import { AuthScreen } from "./components/AuthScreen";
import { ChatArea } from "./components/ChatArea";
import { ChatIcon, Spinner } from "./components/Icons";
import { SetupScreen } from "./components/SetupScreen";
import { Sidebar } from "./components/Sidebar";

function ChatLayout({ userId, username, onSignOut }: { userId: string; username: string; onSignOut: () => void }) {
  const { groups, loading, error, createGroup } = useGroups(userId);
  const [activeId, setActiveId] = useState<string | null>(null);
  // Sur mobile : true = liste des groupes, false = conversation
  const [showList, setShowList] = useState(true);

  // Sur ordinateur, ouvre automatiquement « Général » (ou le premier groupe)
  useEffect(() => {
    if (activeId || groups.length === 0) return;
    if (window.matchMedia("(min-width: 768px)").matches) {
      const general = groups.find((g) => g.name.toLowerCase() === "général") ?? groups[0];
      setActiveId(general.id);
      setShowList(false);
    }
  }, [groups, activeId]);

  const handleSelect = useCallback((id: string) => {
    setActiveId(id);
    setShowList(false);
  }, []);

  const activeGroup = groups.find((g) => g.id === activeId) ?? null;

  return (
    <div className="flex h-dvh w-full overflow-hidden bg-white">
      <Sidebar
        className={`${showList ? "flex" : "hidden"} w-full md:flex md:w-80 md:shrink-0`}
        groups={groups}
        loading={loading}
        error={error}
        activeId={activeId}
        username={username}
        onSelect={handleSelect}
        onCreate={createGroup}
        onSignOut={onSignOut}
      />

      <main className={`${showList ? "hidden" : "flex"} min-w-0 flex-1 md:flex`}>
        {activeGroup ? (
          <ChatArea
            key={activeGroup.id}
            group={activeGroup}
            me={{ id: userId, username }}
            onBack={() => setShowList(true)}
          />
        ) : (
          <div className="flex flex-1 flex-col items-center justify-center bg-slate-50 p-6 text-center text-slate-500">
            <div className="mb-3 flex h-16 w-16 items-center justify-center rounded-2xl bg-indigo-100 text-indigo-600">
              <ChatIcon width={32} height={32} />
            </div>
            <p className="font-semibold text-slate-700">Sélectionnez un groupe</p>
            <p className="text-sm">Choisissez une discussion dans la liste ou créez-en une nouvelle.</p>
          </div>
        )}
      </main>
    </div>
  );
}

function Root() {
  const { session, user, username, loading, signOut } = useAuth();

  if (loading) {
    return (
      <div className="flex min-h-dvh items-center justify-center bg-slate-50 text-slate-500">
        <Spinner className="mr-2 h-6 w-6 text-indigo-500" />
        Chargement…
      </div>
    );
  }

  // Aucun visiteur anonyme : seul l'écran de connexion / inscription est visible
  if (!session || !user) return <AuthScreen />;

  return <ChatLayout key={user.id} userId={user.id} username={username} onSignOut={signOut} />;
}

export default function App() {
  if (!isSupabaseConfigured) return <SetupScreen />;
  return (
    <AuthProvider>
      <Root />
    </AuthProvider>
  );
}

import { useState, type FormEvent } from "react";
import { useAuth } from "../context/AuthContext";
import { ChatIcon, Spinner } from "./Icons";

type Mode = "login" | "signup";

const inputClass =
  "w-full rounded-xl border border-slate-300 bg-white px-4 py-3 text-base text-slate-900 placeholder-slate-400 outline-none transition focus:border-indigo-500 focus:ring-4 focus:ring-indigo-100 disabled:bg-slate-100";

export function AuthScreen() {
  const { signIn, signUp } = useAuth();
  const [mode, setMode] = useState<Mode>("login");
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [username, setUsername] = useState("");
  const [submitting, setSubmitting] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [info, setInfo] = useState<string | null>(null);

  const switchMode = (next: Mode) => {
    setMode(next);
    setError(null);
    setInfo(null);
  };

  const handleSubmit = async (e: FormEvent) => {
    e.preventDefault();
    if (submitting) return;
    setError(null);
    setInfo(null);

    if (mode === "signup") {
      const name = username.trim();
      if (name.length < 3 || name.length > 20) {
        setError("Le pseudo doit contenir entre 3 et 20 caractères.");
        return;
      }
      if (password.length < 6) {
        setError("Mot de passe trop court : 6 caractères minimum.");
        return;
      }
    }

    setSubmitting(true);
    try {
      if (mode === "login") {
        const res = await signIn(email, password);
        if (res.error) setError(res.error);
      } else {
        const res = await signUp(email, password, username);
        if (res.error) {
          setError(res.error);
        } else if (res.needsConfirmation) {
          setInfo(
            "Compte créé ! Vérifiez vos emails et cliquez sur le lien de confirmation, puis connectez-vous."
          );
          setMode("login");
          setPassword("");
        }
      }
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <div className="flex min-h-dvh items-center justify-center bg-gradient-to-br from-indigo-50 via-white to-violet-100 p-4">
      <div className="w-full max-w-md">
        <div className="mb-6 flex flex-col items-center text-center">
          <div className="mb-3 flex h-14 w-14 items-center justify-center rounded-2xl bg-gradient-to-br from-indigo-500 to-violet-600 text-white shadow-lg shadow-indigo-200">
            <ChatIcon width={28} height={28} />
          </div>
          <h1 className="text-2xl font-bold text-slate-900">Discussions de groupe</h1>
          <p className="mt-1 text-sm text-slate-500">
            Connectez-vous pour rejoindre la conversation.
          </p>
        </div>

        <div className="rounded-2xl bg-white p-6 shadow-xl ring-1 ring-slate-200 sm:p-8">
          <div className="mb-6 grid grid-cols-2 gap-1 rounded-xl bg-slate-100 p-1" role="tablist">
            {(["login", "signup"] as const).map((m) => (
              <button
                key={m}
                type="button"
                role="tab"
                aria-selected={mode === m}
                onClick={() => switchMode(m)}
                className={`rounded-lg py-2 text-sm font-semibold transition ${
                  mode === m ? "bg-white text-indigo-600 shadow-sm" : "text-slate-500 hover:text-slate-700"
                }`}
              >
                {m === "login" ? "Connexion" : "Inscription"}
              </button>
            ))}
          </div>

          <form onSubmit={handleSubmit} className="space-y-4" noValidate={false}>
            {mode === "signup" && (
              <div>
                <label htmlFor="username" className="mb-1.5 block text-sm font-medium text-slate-700">
                  Pseudo
                </label>
                <input
                  id="username"
                  type="text"
                  required
                  minLength={3}
                  maxLength={20}
                  autoComplete="username"
                  value={username}
                  onChange={(e) => setUsername(e.target.value)}
                  disabled={submitting}
                  placeholder="Votre pseudo (unique)"
                  className={inputClass}
                />
              </div>
            )}

            <div>
              <label htmlFor="email" className="mb-1.5 block text-sm font-medium text-slate-700">
                Email
              </label>
              <input
                id="email"
                type="email"
                required
                autoComplete="email"
                value={email}
                onChange={(e) => setEmail(e.target.value)}
                disabled={submitting}
                placeholder="vous@exemple.com"
                className={inputClass}
              />
            </div>

            <div>
              <label htmlFor="password" className="mb-1.5 block text-sm font-medium text-slate-700">
                Mot de passe
              </label>
              <input
                id="password"
                type="password"
                required
                minLength={mode === "signup" ? 6 : undefined}
                autoComplete={mode === "login" ? "current-password" : "new-password"}
                value={password}
                onChange={(e) => setPassword(e.target.value)}
                disabled={submitting}
                placeholder={mode === "signup" ? "6 caractères minimum" : "Votre mot de passe"}
                className={inputClass}
              />
            </div>

            {error && (
              <div role="alert" className="rounded-xl border border-red-200 bg-red-50 px-4 py-3 text-sm text-red-700">
                {error}
              </div>
            )}
            {info && (
              <div role="status" className="rounded-xl border border-emerald-200 bg-emerald-50 px-4 py-3 text-sm text-emerald-800">
                {info}
              </div>
            )}

            <button
              type="submit"
              disabled={submitting}
              className="flex w-full items-center justify-center gap-2 rounded-xl bg-gradient-to-r from-indigo-600 to-violet-600 px-4 py-3 text-base font-semibold text-white shadow-lg shadow-indigo-200 transition hover:from-indigo-500 hover:to-violet-500 focus:outline-none focus:ring-4 focus:ring-indigo-200 disabled:cursor-not-allowed disabled:opacity-70"
            >
              {submitting && <Spinner />}
              {submitting
                ? mode === "login"
                  ? "Connexion…"
                  : "Création du compte…"
                : mode === "login"
                  ? "Se connecter"
                  : "Créer mon compte"}
            </button>
          </form>
        </div>
      </div>
    </div>
  );
}

import { useEffect, useRef, useState, type FormEvent, type KeyboardEvent } from "react";
import { SendIcon, Spinner } from "./Icons";

interface Props {
  groupId: string;
  groupName: string;
  onSend: (content: string) => Promise<{ error?: string }>;
}

export function MessageInput({ groupId, groupName, onSend }: Props) {
  const [text, setText] = useState("");
  const [sending, setSending] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const lockRef = useRef(false); // protège contre le double envoi (avant re-render)
  const textareaRef = useRef<HTMLTextAreaElement>(null);

  // Réinitialise la saisie quand on change de groupe
  useEffect(() => {
    setText("");
    setError(null);
  }, [groupId]);

  // Hauteur auto du champ de saisie
  useEffect(() => {
    const el = textareaRef.current;
    if (!el) return;
    el.style.height = "auto";
    el.style.height = `${Math.min(el.scrollHeight, 140)}px`;
  }, [text]);

  const submit = async () => {
    const content = text.trim();
    if (!content || lockRef.current) return;

    lockRef.current = true;
    setSending(true);
    setError(null);
    const res = await onSend(content);
    lockRef.current = false;
    setSending(false);

    if (res.error) {
      setError(res.error);
    } else {
      setText("");
    }
    textareaRef.current?.focus();
  };

  const handleSubmit = (e: FormEvent) => {
    e.preventDefault();
    void submit();
  };

  const handleKeyDown = (e: KeyboardEvent<HTMLTextAreaElement>) => {
    if (e.key === "Enter" && !e.shiftKey && !e.nativeEvent.isComposing) {
      e.preventDefault();
      void submit();
    }
  };

  const canSend = text.trim().length > 0 && !sending;

  return (
    <form
      onSubmit={handleSubmit}
      className="border-t border-slate-200 bg-white p-3 pb-[max(0.75rem,env(safe-area-inset-bottom))] sm:p-4"
    >
      {error && (
        <p role="alert" className="mb-2 rounded-lg bg-red-50 px-3 py-2 text-sm text-red-700">
          {error}
        </p>
      )}
      <div className="flex items-end gap-2">
        <textarea
          ref={textareaRef}
          value={text}
          onChange={(e) => setText(e.target.value)}
          onKeyDown={handleKeyDown}
          rows={1}
          maxLength={2000}
          placeholder={`Écrire dans #${groupName}…`}
          aria-label="Votre message"
          className="max-h-36 min-h-[46px] flex-1 resize-none rounded-2xl border border-slate-300 bg-slate-50 px-4 py-3 text-base text-slate-900 placeholder-slate-400 outline-none transition focus:border-indigo-500 focus:bg-white focus:ring-4 focus:ring-indigo-100"
        />
        <button
          type="submit"
          disabled={!canSend}
          className="flex h-[46px] items-center gap-2 rounded-2xl bg-indigo-600 px-4 font-semibold text-white shadow-sm transition hover:bg-indigo-500 focus:outline-none focus:ring-4 focus:ring-indigo-200 disabled:cursor-not-allowed disabled:bg-slate-300 sm:px-5"
        >
          {sending ? <Spinner className="h-5 w-5" /> : <SendIcon width={18} height={18} />}
          <span>Envoyer</span>
        </button>
      </div>
    </form>
  );
}

  const [profileName, setProfileName] = useState<string | null>(null);

  // Session initiale + écoute des changements d'état d'authentification
  useEffect(() => {
    let active = true;

    supabase.auth.getSession().then(({ data }) => {
      if (!active) return;
      setSession(data.session);
      setLoading(false);
    });

    const { data: listener } = supabase.auth.onAuthStateChange((_event, newSession) => {
      setSession(newSession);
      setLoading(false);
    });

    return () => {
      active = false;
      listener.subscription.unsubscribe();
    };
  }, []);

  const userId = session?.user.id ?? null;

  // Récupération du pseudo depuis la table profiles
  useEffect(() => {
    if (!userId) {
      setProfileName(null);
      return;
    }
    let active = true;
    supabase
      .from("profiles")
      .select("username")
      .eq("id", userId)
      .maybeSingle()
      .then(({ data }) => {
        if (active && data?.username) setProfileName(data.username as string);
      });
    return () => {
      active = false;
    };
  }, [userId]);

  const signIn = useCallback(async (email: string, password: string) => {
    const { error } = await supabase.auth.signInWithPassword({
      email: email.trim(),
      password,
    });
    if (error) return { error: translateAuthError(error) };
    return {};
  }, []);

  const signUp = useCallback(
    async (email: string, password: string, username: string): Promise<SignUpResult> => {
      const cleanName = username.trim();

      // Vérification préalable (facultative) de l'unicité du pseudo
      const { data: available, error: rpcError } = await supabase.rpc("is_username_available", {
        p_username: cleanName,
      });
      if (!rpcError && available === false) {
        return { error: "Ce pseudo est déjà utilisé. Choisissez-en un autre." };
      }

      const { data, error } = await supabase.auth.signUp({
        email: email.trim(),
        password,
        options: { data: { username: cleanName } },
      });

      if (error) return { error: translateAuthError(error) };

      // Avec la confirmation email activée, Supabase renvoie un utilisateur
      // sans identité quand l'adresse existe déjà (anti-énumération).
      if (data.user && Array.isArray(data.user.identities) && data.user.identities.length === 0) {
        return {
          error: "Cette adresse email est déjà utilisée. Connectez-vous ou utilisez une autre adresse.",
        };
      }

      // Pas de session = confirmation par email requise
      if (!data.session) return { needsConfirmation: true };

      return {};
    },
    []
  );

  const signOut = useCallback(async () => {
    await supabase.auth.signOut();
    setSession(null);
  }, []);

  const value = useMemo<AuthContextValue>(() => {
    const user = session?.user ?? null;
    const metaName =
      typeof user?.user_metadata?.username === "string" ? (user.user_metadata.username as string) : "";
    return {
      session,
      user,
      username: profileName ?? (metaName || "Moi"),
      loading,
      signIn,
      signUp,
      signOut,
    };
  }, [session, profileName, loading, signIn, signUp, signOut]);

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

// eslint-disable-next-line react-refresh/only-export-components
export function useAuth(): AuthContextValue {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error("useAuth doit être utilisé dans un AuthProvider");
  return ctx;
}

import { useCallback, useEffect, useState } from "react";
import { supabase } from "../lib/supabase";
import { translateDbError } from "../lib/errors";
import type { Group } from "../types";

function sortGroups(list: Group[]): Group[] {
  return [...list].sort(
    (a, b) => Date.parse(a.created_at) - Date.parse(b.created_at)
  );
}

function upsertGroup(list: Group[], group: Group): Group[] {
  if (list.some((g) => g.id === group.id)) return list;
  return sortGroups([...list, group]);
}

export function useGroups(userId: string) {
  const [groups, setGroups] = useState<Group[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;

    const load = async (initial: boolean) => {
      const { data, error: err } = await supabase
        .from("groups")
        .select("id, name, created_by, created_at")
        .order("created_at", { ascending: true });
      if (cancelled) return;
      if (err) {
        if (initial) setError(translateDbError(err));
      } else {
        setError(null);
        setGroups((prev) => {
          let merged = sortGroups((data ?? []) as Group[]);
          for (const g of prev) merged = upsertGroup(merged, g);
          return merged;
        });
      }
      if (initial) setLoading(false);
    };

    load(true);

    // Les nouveaux groupes apparaissent en direct chez tous les membres
    const channel = supabase
      .channel(`groups:${crypto.randomUUID()}`)
      .on(
        "postgres_changes",
        { event: "INSERT", schema: "public", table: "groups" },
        (payload) => {
          const g = payload.new as Group;
          setGroups((prev) => upsertGroup(prev, g));
        }
      )
      .subscribe((status) => {
        if (status === "SUBSCRIBED") load(false);
      });

    return () => {
      cancelled = true;
      supabase.removeChannel(channel);
    };
  }, [userId]);

  const createGroup = useCallback(
    async (name: string): Promise<{ group?: Group; error?: string }> => {
      const clean = name.trim().replace(/\s+/g, " ");
      if (!clean) return { error: "Le nom du groupe ne peut pas être vide." };
      if (clean.length > 40) return { error: "Le nom du groupe est trop long (40 caractères maximum)." };

      const { data, error: err } = await supabase
        .from("groups")
        .insert({ name: clean, created_by: userId })
        .select("id, name, created_by, created_at")
        .single();

      if (err || !data) return { error: translateDbError(err) };
      const group = data as Group;
      setGroups((prev) => upsertGroup(prev, group));
      return { group };
    },
    [userId]
  );

  return { groups, loading, error, createGroup };
}

import { useCallback, useEffect, useRef, useState } from "react";
import { supabase } from "../lib/supabase";
import { translateDbError } from "../lib/errors";
import type { Message, RawMessage } from "../types";

const HISTORY_LIMIT = 200;
const SELECT_WITH_AUTHOR = "id, group_id, user_id, content, created_at, profiles(username)";
const UNKNOWN_USER = "Utilisateur";

function normalize(raw: RawMessage): Message {
  const p = Array.isArray(raw.profiles) ? raw.profiles[0] : raw.profiles;
  return {
    id: raw.id,
    group_id: raw.group_id,
    user_id: raw.user_id,
    content: raw.content,
    created_at: raw.created_at,
    username: p?.username ?? UNKNOWN_USER,
  };
}

function byDate(a: Message, b: Message): number {
  return Date.parse(a.created_at) - Date.parse(b.created_at);
}

/** Ajoute un message sans doublon (clé : id) et garde l'ordre chronologique. */
function addUnique(list: Message[], msg: Message): Message[] {
  if (list.some((m) => m.id === msg.id)) return list;
  return [...list, msg].sort(byDate);
}

/**
 * Fusionne l'historique chargé (source de vérité) avec l'état local :
 * on garde uniquement les messages locaux plus récents que le dernier
 * message chargé (arrivés en temps réel pendant la requête).
 */
function mergeHistory(local: Message[], fetched: Message[]): Message[] {
  const ids = new Set(fetched.map((m) => m.id));
  const newest = fetched.length ? Date.parse(fetched[fetched.length - 1].created_at) : 0;
  const extras = local.filter((m) => !ids.has(m.id) && Date.parse(m.created_at) > newest);
  return [...fetched, ...extras].sort(byDate);
}

export function useMessages(groupId: string | null, me: { id: string; username: string }) {
  const [messages, setMessages] = useState<Message[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [connected, setConnected] = useState(false);

  const meRef = useRef(me);
  useEffect(() => {
    meRef.current = me;
  }, [me]);

  useEffect(() => {
    setMessages([]);
    setError(null);
    setConnected(false);

    if (!groupId) {
      setLoading(false);
      return;
    }

    let cancelled = false;
    setLoading(true);

    // Cache pseudo par user_id pour les messages reçus en temps réel
    const names = new Map<string, string>([[meRef.current.id, meRef.current.username]]);

    const fetchHistory = async (initial: boolean) => {
      const { data, error: err } = await supabase
        .from("messages")
        .select(SELECT_WITH_AUTHOR)
        .eq("group_id", groupId)
        .order("created_at", { ascending: false })
        .limit(HISTORY_LIMIT);

      if (cancelled) return;

      if (err) {
        if (initial) setError(translateDbError(err));
        setLoading(false);
        return;
      }

      const fetched = ((data ?? []) as unknown as RawMessage[]).map(normalize).reverse();
      for (const m of fetched) names.set(m.user_id, m.username);
      setError(null);
      setMessages((prev) => mergeHistory(prev, fetched));
      setLoading(false);
    };

    const resolveUsername = async (userId: string): Promise<string> => {
      const cached = names.get(userId);
      if (cached) return cached;
      const { data } = await supabase
        .from("profiles")
        .select("username")
        .eq("id", userId)
        .maybeSingle();
      const name = (data?.username as string | undefined) ?? UNKNOWN_USER;
      names.set(userId, name);
      return name;
    };

    fetchHistory(true);

    const channel = supabase
      .channel(`messages:${groupId}:${crypto.randomUUID()}`)
      // Nouveaux messages du groupe courant (filtre côté serveur)
      .on(
        "postgres_changes",
        { event: "INSERT", schema: "public", table: "messages", filter: `group_id=eq.${groupId}` },
        async (payload) => {
          const row = payload.new as Omit<RawMessage, "profiles">;
          const username = await resolveUsername(row.user_id);
          if (cancelled) return;
          setMessages((prev) => addUnique(prev, { ...row, username }));
        }
      )
      // Supprimations : Supabase ne permet pas de filtrer les DELETE par colonne
      // (seule la clé primaire est fournie). On retire donc simplement l'id
      // s'il est présent dans la liste courante.
      .on(
        "postgres_changes",
        { event: "DELETE", schema: "public", table: "messages" },
        (payload) => {
          const id = (payload.old as { id?: string }).id;
          if (!id) return;
          setMessages((prev) => (prev.some((m) => m.id === id) ? prev.filter((m) => m.id !== id) : prev));
        }
      )
      .subscribe((status) => {
        if (cancelled) return;
        if (status === "SUBSCRIBED") {
          setConnected(true);
          // Rattrape les éventuels messages manqués (connexion initiale ou reconnexion)
          fetchHistory(false);
        } else if (status === "CHANNEL_ERROR" || status === "TIMED_OUT" || status === "CLOSED") {
          setConnected(false);
        }
      });

    return () => {
      cancelled = true;
      supabase.removeChannel(channel);
    };
  }, [groupId, me.id]);

  const send = useCallback(
    async (content: string): Promise<{ error?: string }> => {
      const text = content.trim();
      if (!groupId) return { error: "Aucun groupe sélectionné." };
      if (!text) return { error: "Le message est vide." };

      const current = meRef.current;
      const { data, error: err } = await supabase
        .from("messages")
        .insert({ group_id: groupId, user_id: current.id, content: text })
        .select("id, group_id, user_id, content, created_at")
        .single();

      if (err || !data) return { error: translateDbError(err) };

      // Affichage immédiat ; l'évènement temps réel du même message sera ignoré (même id)
      setMessages((prev) => addUnique(prev, { ...(data as Omit<RawMessage, "profiles">), username: current.username }));
      return {};
    },
    [groupId]
  );

  const remove = useCallback(async (id: string): Promise<{ error?: string }> => {
    const { error: err } = await supabase.from("messages").delete().eq("id", id);
    if (err) return { error: translateDbError(err) };
    setMessages((prev) => prev.filter((m) => m.id !== id));
    return {};
  }, []);

  return { messages, loading, error, connected, send, remove };
}

interface ErrorLike {
  message?: string;
  code?: string;
  status?: number;
}

/** Traduit une erreur Supabase Auth en message français lisible. */
export function translateAuthError(error: ErrorLike | null | undefined): string {
  if (!error) return "Une erreur inconnue est survenue.";
  const msg = (error.message ?? "").toLowerCase();
  const code = (error.code ?? "").toLowerCase();

  if (code === "invalid_credentials" || msg.includes("invalid login credentials")) {
    return "Email ou mot de passe incorrect.";
  }
  if (code === "email_not_confirmed" || msg.includes("email not confirmed")) {
    return "Votre email n'est pas encore confirmé. Vérifiez votre boîte mail (et vos spams) puis cliquez sur le lien reçu.";
  }
  if (
    code === "user_already_exists" ||
    code === "email_exists" ||
    msg.includes("already registered") ||
    msg.includes("already been registered")
  ) {
    return "Cette adresse email est déjà utilisée. Connectez-vous ou utilisez une autre adresse.";
  }
  if (code === "weak_password" || msg.includes("password should be at least") || msg.includes("weak password")) {
    return "Mot de passe trop court ou trop faible : 6 caractères minimum.";
  }
  if (code === "validation_failed" || msg.includes("unable to validate email") || msg.includes("invalid email")) {
    return "Adresse email invalide.";
  }
  if (msg.includes("database error saving new user")) {
    return "Impossible de créer le compte : ce pseudo est probablement déjà utilisé ou invalide.";
  }
  if (code === "over_email_send_rate_limit" || msg.includes("rate limit") || error.status === 429) {
    return "Trop de tentatives. Patientez quelques instants avant de réessayer.";
  }
  if (code === "signup_disabled" || msg.includes("signups not allowed")) {
    return "Les inscriptions sont désactivées pour le moment.";
  }
  if (msg.includes("failed to fetch") || msg.includes("networkerror") || msg.includes("network request failed")) {
    return "Connexion impossible au serveur. Vérifiez votre connexion internet.";
  }
  return "Une erreur est survenue. Veuillez réessayer.";
}

/** Traduit une erreur PostgREST / base de données en message français. */
export function translateDbError(error: ErrorLike | null | undefined): string {
  if (!error) return "Une erreur inconnue est survenue.";
  const msg = (error.message ?? "").toLowerCase();

  if (error.code === "23505" || msg.includes("duplicate key")) {
    return "Un groupe porte déjà ce nom.";
  }
  if (error.code === "42501" || msg.includes("row-level security")) {
    return "Action non autorisée.";
  }
  if (error.code === "23514") {
    return "Contenu invalide (trop long ou vide).";
  }
  if (msg.includes("failed to fetch") || msg.includes("networkerror")) {
    return "Connexion impossible au serveur. Vérifiez votre connexion internet.";
  }
  return "Une erreur est survenue. Veuillez réessayer.";
}

export function formatTime(iso: string): string {
  return new Date(iso).toLocaleTimeString("fr-FR", {
    hour: "2-digit",
    minute: "2-digit",
  });
}

export function dayKey(iso: string): string {
  const d = new Date(iso);
  return `${d.getFullYear()}-${d.getMonth()}-${d.getDate()}`;
}

export function formatDay(iso: string): string {
  const d = new Date(iso);
  const today = new Date();
  const yesterday = new Date();
  yesterday.setDate(today.getDate() - 1);

  if (dayKey(iso) === dayKey(today.toISOString())) return "Aujourd'hui";
  if (dayKey(iso) === dayKey(yesterday.toISOString())) return "Hier";

  return d.toLocaleDateString("fr-FR", {
    weekday: "long",
    day: "numeric",
    month: "long",
    year: d.getFullYear() === today.getFullYear() ? undefined : "numeric",
  });
}

export function avatarColor(seed: string): string {
  let hash = 0;
